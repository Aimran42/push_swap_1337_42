# Description;

Push_swap is a C project that sorts a list of integers using a limited set of stack operations while minimizing the number of moves.

The program uses two stacks, `a` and `b`, and provides operations such as `sa`, `sb`, `pa`, `pb`, `ra`, `rb`, `rra`, `rrb`,

and their combinations.

The project includes a mandatory part (`push_swap`) that generates the sequence of operations to sort the input, and a bonus part (`checker`) that verifies whether a given sequence of operations correctly sorts the list.


# Instructions;

To use the project, clone the repository, navigate to the folder, compile the program with `make` (or `make bonus` for the checker), and the

run `./push_swap <list_of_integers>` to generate sorting operations, and `./checker <list_of_integers>` to check a sequence of operations. Example usage: `./push_swap 2 1 3` outputs `sa`, and `./checker 2 1 3` with `sa` prints `OK`.
